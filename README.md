## Overview

Smart Contact Manager (SCM) is a web-based contact management
application designed to help users store, manage, search, and
communicate with their contacts.

## Features

- User registration and login
- Email verification
- Google and GitHub login
- Add contacts
- View contact details
- Edit contact details
- Delete contacts
- Upload contact pictures
- Search contacts
- Pagination
- Favorite contacts
- Send emails with attachments
- Export contact data
- User profile management
- Theme support
- Feedback functionality

## Technologies

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Spring Security
- OAuth
- Thymeleaf
- MySQL
- JavaScript
- Tailwind CSS
- Flowbite
